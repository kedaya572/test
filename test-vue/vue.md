test-vue 项目命令文档

技术栈： Vue 3 + Vite + Vue Router + Axios
                                                                                                                                                                     
---
安装依赖

npm install
                                                                                                                                                                     
---             
开发环境启动

npm run dev

启动本地开发服务器（默认地址：http://localhost:5173），支持热更新（HMR）。
   
---                                                                                                                                                                
生产构建

npm run build

将项目打包到 dist/ 目录，输出优化后的静态资源。
   
---                                                                                                                                                                
预览生产构建

npm run preview

在本地预览 npm run build 生成的生产包（默认地址：http://localhost:4173）。
   
---                                                                                                                                                                
常用流程

# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 构建并预览生产版本
npm run build && npm run preview
